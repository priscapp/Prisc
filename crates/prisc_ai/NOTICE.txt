prisc_ai — on-device AI inference (OCR, video matting, audio denoising) for Prisc

This executable (prisc_ai) is part of Prisc and, like the rest of Prisc, is
licensed under the GNU General Public License, version 3 or (at your option)
any later version (GPL-3.0-or-later), with the additional terms in Prisc's
NOTICE.txt. See the accompanying LICENSE.txt file for the full license text.

It embeds the following model weights:

  * RobustVideoMatting (rvm_mobilenetv3_fp32.onnx)
    Copyright (c) Peter Lin — GPL-3.0
    https://github.com/PeterL1n/RobustVideoMatting

  * DPDFNet (dpdfnet2_48khz_hr.onnx)
    Copyright (c) Ceva — Apache-2.0
    https://huggingface.co/Ceva-IP/DPDFNet
    (obtained via the k2-fsa/sherpa-onnx "speech-enhancement-models" release)

  * PaddleOCR PP-OCRv6 text detection and recognition models
    (pp-ocrv6_small_det.onnx, pp-ocrv6_small_rec.onnx, pp-ocrv6_tiny_rec.onnx
    and their character dictionaries ppocrv6_dict.txt, ppocrv6_tiny_dict.txt)
    Copyright (c) PaddlePaddle Authors — Apache-2.0
    https://github.com/PaddlePaddle/PaddleOCR
    (the official ONNX inference exports, obtained as flat files from the
    GreatV/oar-ocr v0.7.0 release)

It statically links ONNX Runtime (MIT, https://github.com/microsoft/onnxruntime)
via the ort crate (Apache-2.0/MIT, https://github.com/pykeio/ort); both licenses
are GPL-compatible. On Windows the DirectML execution-provider helper library
(DirectML.dll) is distributed beside it but not embedded in it.

Complete corresponding source code for prisc_ai is available at:
https://github.com/priscapp/Prisc (the crates/prisc_ai/ directory)
